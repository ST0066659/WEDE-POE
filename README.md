# Paws & Hope

## Project Description

Paws & Hope is a fictional animal rescue and adoption organisation created
as part of a school POE website project.

The website focuses on animal rescue, adoption, fostering, volunteering,
sponsorship and animal welfare.

## Research and Content

The Paws & Hope Animal Rescue website was created as a fictional school
POE project. The content was developed specifically for the project based
on the theme of animal rescue, adoption and animal welfare.

Research was completed using animal welfare organisations and web
development resources. These sources helped provide information about
responsible pet ownership, animal welfare, website development and
accessibility.

The animal rescue images used on the website helped inspire the theme and
visual presentation of the website. The image sources are listed in the
Image References section below.
